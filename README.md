# 📦 React + TypeScript Project

This project is a frontend application built with **React** and **TypeScript**, focused on maintainability, type safety, and clean structure.  
It is configured to work correctly with viewport scaling and modern tooling.

---

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- CSS / CSS Variables
- ESLint

---

## 📂 Project Structure

```txt
src/
├─ components/      # Reusable UI components
├─ data/            # Static or shared data files
├─ styles/          # Global and component styles
├─ App.tsx          # Main application component
├─ main.tsx         # Application entry point
└─ vite-env.d.ts    # Vite environment types

📥 Installation

Clone the repository:
```bash
git clone https://github.com/your-username/react-typescript-project.git
```

Install dependencies:
```bash
cd react-typescript-project
npm install
```

📌 Scripts

Start the development server:
```bash
npm run dev
```

Build the production bundle:
```bash
npm run build
```
